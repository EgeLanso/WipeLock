Temporarily lock keyboard and mouse input with a visible countdown. When time is up, WipeLock unlocks automatically.

Download for Windows View source on GitHub
Free · Windows · Public beta

⏱ Visible countdown

See how much time remains while input is temporarily locked.

⌨ Keyboard & mouse

Temporarily suppresses local keyboard and mouse input during the selected session.

↩ Automatic unlock

Input is restored when the countdown reaches zero.

Safety comes first

Emergency unlock shortcut: Ctrl + Alt + W. The maximum lock duration is five minutes. Use only on your own Windows computer, keep the emergency shortcut in mind, and test this beta before relying on it. Do not use it on shared or managed devices.
